# Product

The first visit, when no app user exists, is a setup wizard: company name, an admin, and a second person who can approve. It does not print a password.

An admin edits policy on the Policy page. Saving uses the same checks as startup and writes the policy file the process loaded. A bad edit is refused.

On the built-in directory, an admin can load a sample company. That action is absent for Entra.

Errors shown to a person do not include the exception. The log keeps the detail. The footer shows IAM Onboarding, the version, and the company name.

Sign in with Microsoft is optional. It matches an existing app user and never creates one. Username and password remain available.
